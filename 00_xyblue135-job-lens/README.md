# xyblue135 · 岗位透镜

输入目标岗位 → AI 结合中国市场行情（模型知识，非实时）生成技能需求画像 → 与「技能提炼」的技能矩阵比对 → 四象限分析与学习方向 Top5。

## 用法

1. 侧栏 compass 图标 → 填目标岗位（可选粘贴真实 JD 原文，粘贴则优先按 JD 分析）→ 开始分析（30~60 秒）
2. 生成报告笔记：匹配度评分 / 技能需求画像（核心·常见·加分）/ 优势 / 差距(P0~P2) / 学习方向 Top5
3. 命令「导出最近分析的学习方向为收件箱待办」→ 5 条待办进 `my_blog/00_docs/收件箱`，待完成工作台接管

## 数据来源与边界

- 技能清单：只读 `00_xyblue135-skill-miner/data.json` 的 `data.refined`（159 簇定级）
- 市场行情：LLM 训练知识（报告内已标注非实时），想要精准行情请粘贴真实 JD
- 网关配置：复用技能提炼的 baseUrl/key，本插件不存密钥

## 学习闭环

岗位透镜（市场要求什么）→ 收件箱待办 → 待完成工作台逐篇处理 → 新笔记提升技能矩阵 → 重跑分析看匹配度上涨。
