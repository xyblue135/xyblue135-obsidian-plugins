# xyblue135 · 知识库导航

用四种可交互视图浏览白名单目录（默认 `00_docs`）的知识结构，数据实时扫描笔记 frontmatter。

## 视图

| 视图 | 编码方式 |
| --- | --- |
| 技能树 | 与「技能提炼」同口径：方向 → 技能簇 → 代表笔记。分支配色 = 方向，😄精通 😐熟练 😢了解 = AI 定级；簇详情含简历句与代表笔记，可一键跳转技能提炼面板。支持横向 / 径向（从圆心辐射）两种布局切换，偏好持久化 |
| 树状图 | 目录层级树，颜色 = 技术深度，半透明 = 未完成；点击展开/收起，滚轮缩放 |
| 旭日图 | 环层 = 目录层级，扇区大小 = Token 量，颜色 = 技术深度 |
| 矩形树图 | 面积 = Token 量，颜色 = 技术深度；点击下钻，面包屑返回 |
| 标签星图 | 力导向标签网络：节点大小 = 出现篇数，连线 = 同篇共现 |

## 交互

- **搜索框**：按文件名 / AI_title / AI_tags 实时过滤，四种视图同时生效。
- **点击节点**：下方卡片显示 AI 标题、状态、可见性、新鲜度、技术深度、Token 数、更新日期与 AI 摘要，可直接「打开笔记」或「复制路径」。
- **重新扫描**：新增/修改笔记后手动刷新数据。
- **设置**：白名单目录（默认 00_docs）、标签数量上限、共现阈值。

## 使用的 frontmatter 字段

`status`、`visibility`、`AI_freshness`、`AI_technical_depth`、`token_count`、`updated`、`AI_tags`、`AI_title`、`AI_summary_short`。缺失字段按空值处理，不影响渲染。

## 与技能提炼的联动

技能树视图运行时只读访问 `00_xyblue135-skill-miner/data.json`：

- `data.refined`：应用 AI 定级（精通/熟练/了解）、AI 方向修正、类别、简历句；
- `settings.tagCanonicalList` / `ignoreTags`：标签规范表与忽略表，簇归一口径与技能提炼一致。

未安装或未运行过技能提炼时自动降级：方向按内置关键词表推断，无定级表情。两边数据互写仍是单向只读，不会修改技能提炼的任何数据。
