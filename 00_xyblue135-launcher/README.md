# xyblue135 · 启动台

Raycast 式插件启动台：一个高亮侧栏图标 + 快捷键，唤起居中浮层，搜索即达全部插件。

## 用法

- 侧栏高亮图标（火箭）或命令「打开启动台」唤起；建议把命令绑成 `Ctrl+J`（设置 → 快捷键）
- 输入即过滤，**方向键选择、Enter 直达**；卡片点击 = 打开主功能；右上角小齿轮 = 设置
- 分区：AI 学习·面试（自研 9 个）/ 工具（7 个）/ 其他插件（全部已启用社区插件）

## 边界

- 纯入口面板：不操控侧边栏（分组/隐藏由 xyblue135-brand CSS 片段负责）
- 社区插件无主命令概念，点击卡片进入其设置页
